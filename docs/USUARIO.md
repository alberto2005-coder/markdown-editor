# 📖 Manual de usuario — Markdown Editor

Guía completa para sacarle el máximo partido a la web. Si solo quieres empezar
rápido, con los tres primeros apartados te bastan.

---

## 1. Primeros pasos

1. Abre **`index.html`** (doble clic), entra en la web publicada en GitHub Pages o **instálalo en Windows** con el instalador de escritorio de la carpeta `desktop/`.
2. Verás la pantalla **partida en dos**: escribes a la **izquierda** 👉 y el
   resultado aparece a la **derecha** al instante.
3. Escribe tu título con `#` y dale a `**negrita**`… o usa los botones de arriba:
   no hace falta que memorices nada.
4. Tu trabajo se **guarda solo** (autoguardado). No hay que pulsar nada.
5. ¿Prefieres el inglés? Pulsa **🌐 EN** en la barra superior: toda la web
   cambia al instante (**🌐 ES** la vuelve a poner en español).

> 💡 La primera vez aparece un documento de ejemplo. Púlsalo, tócalo, y cuando
> quieras empieza el tuyo con **＋ Nuevo** (abre el menú de plantillas: apuntes,
> README, informe, tareas o simplemente en blanco).

## 2. Qué hay en pantalla

| Zona | Qué es | Qué puedes hacer |
|---|---|---|
| **Barra superior** | Nombre del documento + botones principales | Renombrar (escribiendo en el nombre), crear con plantilla, abrir, guardar, biblioteca, exportar, ajustes, guía, tema e **idioma** |
| **Barra de formato** | Fila de botones justo debajo | Deshacer/rehacer, formato sin recordar sintaxis, buscar y elegir modo de vista |
| **Editor ✍️** | Columna izquierda | Escribir Markdown |
| **Esquema 📑** | Columna estrecha del centro | Índice de títulos; clic = saltar ahí |
| **Vista previa 👀** | Columna derecha | Cómo se verá al publicar |
| **Pie** | Barra inferior | Mensajes, estado del guardado y atajos |

## 3. Los botones, uno por uno

### Barra superior

| Botón | Qué hace | Atajo |
|---|---|---|
| **＋ Nuevo** | Abre el **menú de plantillas**: en blanco, apuntes, README, informe o tareas (el actual se guarda antes) | `Ctrl+N` (en blanco) |
| **📂 Abrir** | Carga un `.md` que ya tengas en tu PC — o **arrástralo** a la ventana | `Ctrl+O` |
| **💾 Guardar** | Guarda en la biblioteca **y** descarga el archivo `.md` | `Ctrl+S` |
| **📚 Mis docs** | Ventana con todos tus documentos: abrir (clic), **🕘 versiones**, renombrar ✏️, borrar 🗑️ — y **papelera** para restaurar, **⬇️ Respaldo**, **📦 ZIP** y **⬆️ Restaurar** | — |
| **📤 Exportar ▾** | Menú: `.md`, HTML, PDF, copiar y **enlace para compartir** | — |
| **⚙️ Ajustes** | Fuente, tamaño del editor, tamaño de la vista previa, ancho de lectura, tema e **idioma** | — |
| **❓ Guía** | Guía rápida de sintaxis y atajos | — |
| **🌐 EN / 🌐 ES** | Cambia **el idioma de toda la interfaz** (español ↔ inglés) al instante | — |
| **🌙 / ☀️** | Tema oscuro / claro (se recuerda) | — |
| **Nombre del documento** | Escribir ahí cambia el nombre del archivo | — |

### Barra de formato

| Botón | Qué hace |
|---|---|
| **↶ Deshacer / ↷ Rehacer** | Deshace lo que has hecho (también `Ctrl+Z`, `Ctrl+Y`) |
| **H1 H2 H3** | Título grande / mediano / pequeño. Si la línea está vacía deja `Título 1` seleccionado: **escribes y lo sustituye** |
| **B / I / S** | Negrita, cursiva, tachado |
| **`</>`** | Código dentro de una frase |
| **• Lista / 1. Numerada / ☑ Tareas** | Listas; igual que los títulos, dejan un ejemplo seleccionado |
| **❝ Cita** | Frase destacada con barra azul |
| **🔗 Enlace / 🖼 Imagen** | Insertan la plantilla con el texto seleccionado para que solo pegues la dirección |
| **📊 Tabla ▾** | Abre una **rejilla como en Word**: pasa el ratón, mira el tamaño (`4 × 3`) y haz clic |
| **{ } Bloque** | Bloque de código de varias líneas |
| **─ Regla** | Línea separadora |
| **🔍 Buscar** | Abre **buscar y reemplazar** (`Ctrl+F`): contador `n/total`, *Aa* para distinguir mayúsculas, *Siguiente*, *Reemplazar* y *Todo* |
| **✍️ ◫ 👀** | **Modo de vista**: solo editor, pantalla dividida o solo vista previa (se recuerda) |

> Los botones de títulos, listas y cita **alternan**: si la línea ya tiene el
> formato, al pulsarlo se quita.

## 4. Los gestos que más usarás

### ✍️ Escribir un documento
Escribe con libertad; la vista previa se actualiza sola. Usa el **esquema** de la
centro para moverte por títulos largos (va resaltando por dónde vas).

### 💾 Guardar
- **Automático:** deja de escribir 1 segundo y ya está guardado (el pie lo dice).
- **Con archivo:** `💾 Guardar` → te baja `nombre-del-documento.md`.
- **Volver a un documento:** `📚 Mis docs` → clic.

### 📤 Exportar / mandar a alguien
- **PDF:** 📤 Exportar → *Imprimir / PDF* → en el diálogo elige **Guardar como PDF**.
- **HTML:** 📤 Exportar → *Exportar como página HTML* → te baja una página con
  estilo propia, lista para abrir o subir a internet.
- **A otra persona:** 📤 Exportar → *Copiar enlace para compartir* y se lo pegas
  (WhatsApp, correo…). Al abrirlo le aparece suyo, guardado como `compartido`.
  *Nota: sirve para documentos medianos; si es muy grande, manda el `.md`.*

### 🖼 Meter una captura de pantalla
1. Haz la captura (`Win+Shift+S` en Windows).
2. Pon el cursor donde quieras y `Ctrl+V`.
3. La imagen se convierte en parte del Markdown y se ve a la derecha.

*También vale **arrastrar** la imagen desde el explorador hasta la ventana.*

### 🔍 Buscar y reemplazar
`Ctrl+F` (o **🔍 Buscar**) abre una barra con todo lo necesario:

1. Escribe qué buscar → el contador dice `1/3` y la coincidencia se selecciona.
2. **Aa** activa/desactiva que importen las mayúsculas.
3. **Siguiente ↓** salta a la siguiente coincidencia (también `Enter`).
4. Escribe el texto nuevo y usa **Reemplazar** (la de ahora) o **Todo** (todas).
5. `Esc` cierra la barra.

### 🗂 Cambiar de modo y ajustar el texto
- **✍️ ◫ 👀** (derecha de la barra de formato): solo editor para concentrarte,
  dividido para ver todo, solo vista previa para leer o leerle a alguien.
- **⚙️ Ajustes**: elige fuente (monoespaciada, sans serif o serif), tamaño del
  editor y de la vista previa, ancho de lectura, tema e **idioma**. Se guarda
  solo y hay un botón para **restablecer** los valores.

### 📂 Abrir arrastrando
Arrastra un archivo `.md` o `.txt` desde el explorador y se abre en la ventana
(la zona de aviso te confirma dónde soltar). Si sueltas una imagen, se inserta
igual que con `Ctrl+V`.

### 🧳 Respaldar la biblioteca
`📚 Mis docs → ⬇️ Respaldo` te baja un `.json` con **todos** tus documentos.
En otro equipo o tras borrar datos del navegador: `⬆️ Restaurar` y lo tienes
todo de vuelta (los documentos existentes no se pisan, se añaden).

### 🌐 Cambiar el idioma (español ↔ inglés)
Toda la interfaz está en los dos idiomas:

1. Pulsa **🌐 EN** en la barra superior para pasar a inglés (entonces dice
   **🌐 ES** para volver).
2. También está en **⚙️ Ajustes → Idioma**.
3. La elección se recuerda; si nunca has cambiado nada, se usa el idioma de tu
   navegador.

*Tus documentos, las plantillas que ya tengas escritas y esta guía no se
traducen: son tuyos y se quedan como los escribiste.*

### 🗑️ Papelera: borrar sin miedo
Borrar ya no es definitivo: el documento pasa a la **papelera**.

1. **📚 Mis docs → 🗑️ Papelera** — el botón muestra cuántos hay (`🗑️ Papelera (2)`).
2. Dentro, cada documento tiene dos botones:
   - **♻️ Restaurar** — vuelve a tu biblioteca igual que estaba.
   - **❌ Borrar para siempre** — te pregunta antes y ya no se puede recuperar.
3. **🗑️ Vaciar papelera** borra todos de golpe (también avisa antes).

Cabe un máximo de **10** documentos; si se pasa, se descartan los más antiguos.
Para salir de la papelera, vuelve a pulsar **↩ Documentos**.

### 📦 Descargar toda la biblioteca en un `.zip`
`📚 Mis docs → 📦 ZIP` te baja `markdown-editor.zip` con **todos** tus
documentos sueltos como archivos `.md`, con nombres que nunca se pisan
(`apuntes.md`, `apuntes (2).md`…). Ideal para llevártelos a otro ordenador o
guardarlos como copia de seguridad legible.

Si prefieres **un solo archivo** que además se puede *restaurar* dentro de la
web, usa **⬇️ Respaldo** (`.json`): el `.zip` es para llevar los `.md` sueltos.

### 🕘 Volver a una versión anterior
Cada vez que guardas (y cada vez que cambias de documento) se guarda una **copia
de seguridad automática**: como mucho **una por minuto** y hasta **20 por
documento**.

1. **📚 Mis docs** → en la fila del documento pulsa **🕘**.
2. Se lista `🕘 Versiones de nombre.md` con la fecha y cuándo se guardó
   (*hace 5 min*), con el número de palabras.
3. Botones de cada versión:
   - **♻️** devuelve el documento a ese momento. Lo que tienes ahora **se guarda
     antes**, así que no pierdes nada ni de lo uno ni de lo otro.
   - **🗑️** borra esa copia (te lo advierte: ya no se recupera).
4. **↩ Documentos** vuelve a la lista normal.

*Si pone «Todavía no hay versiones», es que llevas menos de un minuto en ese
documento: espera un poco y vuelve.*

## 6. Ejemplos de sintaxis

```markdown
# Título 1
## Título 2

**negrita** · *cursiva* · ~~tachado~~ · `código`

- elemento de lista
1. paso numerado
- [ ] tarea pendiente
- [x] tarea hecha

> cita destacada

[texto del enlace](https://ejemplo.com)
![descripción](https://ruta/imagen.jpg)

| Columna 1 | Columna 2 |
|---|---|
| dato | dato |

---
```

También lo tienes todo dentro de la web en **❓ Guía**.

## 7. Ejemplos de uso real

- **Apuntes / cuaderno:** escribe en `.md`, yendo con `##` por temas; guárdalo como
  `apuntes.md` en tu biblioteca y exporta a PDF para imprimirlo.
- **README de un proyecto:** usa listas, tablas y bloques de código; copia el
  Markdown con 📋 *Copiar Markdown* y pégalo en GitHub.
- **Redactar un texto:** activa el tema oscuro, escribe con ❑ *Tareas* para la
  lista de pendientes y deshaz con `Ctrl+Z` sin miedo.
- **Mandar un borrador:** copia el enlace de compartir y quien lo abra lo ve
  renderizado al momento.

## 8. Preguntas frecuentes

**¿Se guarda en la nube?** No, en tu navegador (`localStorage`). Si borras los
datos del navegador, se borra: haz **📚 Mis docs → ⬇️ Respaldo** de vez en
cuando y **⬆️ Restaurar** en el equipo nuevo.

**¿Puedo cambiar la fuente o el tamaño?** Sí: **⚙️ Ajustes** → fuente, tamaño
del editor, tamaño de la vista previa, ancho de lectura, tema e **idioma**.

**¿Funciona sin internet?** Sí para escribir, abrir, guardar y exportar. La vista
previa completa necesita internet la primera vez (usa `marked` por CDN); sin
conexión hay un render básico de respaldo.

**¿Se puede instalar en mi ordenador como app nativa de Windows?** Sí: en la
carpeta `desktop/` dispones del empaquetado para Windows compilable con Inno Setup 7.
Se instala con un asistente tradicional, crea accesos directos en el Menú Inicio
y Escritorio, y te permite usar el editor en una ventana propia sin abrir el navegador.

**¿Puedo usarlo en el móvil?** Sí: las columnas se apilan (editor encima, vista
previa debajo) y el esquema se oculta.

**¿Puedo usarlo en inglés?** Sí: **🌐 EN** en la barra superior o
**⚙️ Ajustes → Idioma**. Se recuerda la próxima vez. Solo cambia la interfaz:
tus documentos se quedan como los escribiste.

**¿He borrado un documento por error?** Si no has vaciado la papelera, sigue
ahí: **📚 Mis docs → 🗑️ Papelera → ♻️** lo devuelve a la biblioteca.

**¿Puedo recuperar un texto que había quitado?** Si llegaste a guardarlo, sí:
**📚 Mis docs → 🕘** en su fila y **♻️** en la versión que quieras. Hay hasta 20
copias por documento y se guarda una como máximo cada minuto.

**¿Y si tengo dos documentos con el mismo nombre?** Pasa: se guardan como
entradas distintas en *Mis docs*. Renombra uno con ✏️.

**¿Puedo abrir un `.md` de otro programa?** Sí, *📂 Abrir* acepta cualquier
archivo `.md`, `.markdown` o `.txt`.

**¿Se puede publicar mi documento?** Sí: *Exportar → HTML* te da una página
lista, o copia el Markdown y pégalo donde quieras.

## 9. Publicar la web (resumen)

1. Crea un repositorio en GitHub y sube **el contenido** de la carpeta
   (`index.html`, `README.md`, `.nojekyll`, `css/`, `js/`, `assets/`).
2. **Settings → Pages → Branch: `main` / `(root)` → Save.**
3. En unos segundos: `https://TU-USUARIO.github.io/markdown-editor/`

El detalle paso a paso está en el [`README.md`](../README.md).
